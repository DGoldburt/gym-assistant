# Agentic-AI Skills

This is a compact confidence record for abilities you are learning to use. It is not a grade. `AGENTIC_AI_MAP.md` holds the broader ideas; `LEARNING_LOG.md` holds the dated evidence and personal reflections.

## Confidence states

- **Not yet used** — relevant to the course, but not yet applied in this project.
- **Used with guidance** — applied with tutorial structure or Codex support.
- **Demonstrated** — you led a real instance and an approved reflection plus observable evidence is recorded in `LEARNING_LOG.md`.
- **Revisit** — a reflection or result exposed a gap worth returning to.

## orient — Orient before changing

**Confidence:** Not yet used
Inspect the repository, instructions, architecture, tooling, and uncertainty before modifying anything.  

## frame-work — Frame a bounded task

**Confidence:** Not yet used
State the outcome, relevant context, constraints, verification evidence, and stopping condition before work begins.  

## plan — Plan in proportion to risk

**Confidence:** Not yet used
Use a lightweight prompt for mechanical work and a durable, read-only plan for consequential uncertainty; match reasoning effort to the decision at stake.  

## set-boundaries — Control autonomy safely

**Confidence:** Not yet used
Define what the agent may do, what requires explicit approval, and when it must stop for a human decision.  

## collaborate — Work through reviewable Git collaboration

**Confidence:** Not yet used
Use commits, branches, remotes, pull requests, reviews, merges, and synchronization to make work inspectable.

## verify — Build an evidence-producing delivery loop

**Confidence:** Not yet used
Turn intended behavior into fixtures, tests, manual artifacts, and reproducible checks that let an agent correct itself.

## record-decisions — Preserve durable technical judgment

**Confidence:** Not yet used  
Record consequential decisions, evidence, tradeoffs, and revisit triggers outside chat.

## review — Challenge work from more than one perspective

**Confidence:** Not yet used
Use self-review, independent review, and worktree or parallel-agent judgment without multiplying work unnecessarily.

## scale-capabilities — Apply advanced capabilities deliberately

**Confidence:** Not yet used  
Use authoritative MCP context, reusable Skills, bounded cloud delegation, and scheduled automation only when the workflow is ready for them.
