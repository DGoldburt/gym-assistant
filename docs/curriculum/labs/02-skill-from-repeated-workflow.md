# Optional Lab 02 — Turn a Repeated Workflow into a Skill

## Skill practiced

- `scale-capabilities` — Apply advanced capabilities deliberately

## Learning objective

Learn to distinguish a one-time prompt, a durable repository convention, and a reusable task procedure. Create a Skill only after the workflow has succeeded repeatedly enough to state its inputs, steps, evidence, and stopping conditions.

## Task

1. Find a workflow that has been completed successfully at least twice.
2. Extract its stable steps, required inputs, reusable assets, verification, and failure behavior.
3. Identify project-specific rules that must remain in `AGENTS.md` rather than the Skill.
4. Propose the smallest Skill and test it on one representative case after approval.

### STOP / REVIEW

Inspect whether the Skill captures a reusable procedure rather than project truth or a one-off request. Compare its result with the earlier manual workflow and decide whether reuse improved consistency without hiding important judgment.

Teach back: What evidence tells you a repeated prompt is mature enough to become a Skill?
