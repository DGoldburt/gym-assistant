# Optional Agentic-AI Labs

These labs extend the agentic-development curriculum without blocking or advancing the 13-exercise product course.

Rules:

- Start a lab only when the user explicitly chooses it.
- Read only the selected lab plus `SKILLS.md`, the relevant map section, and relevant prior ledger entries.
- Preserve every product and engineering boundary in `AGENTS.md`.
- Stop at every `STOP / REVIEW` checkpoint.
- Update `SKILLS.md` and append to `LEARNING_LOG.md` only after the user approves the reflection and checkpoint.
- Do not change `PROGRESS.md` for an optional lab.

Available labs:

- `01-mcp-authoritative-context.md`
- `02-skill-from-repeated-workflow.md`
- `03-cloud-delegation.md`
- `04-stable-before-scheduled.md`
