# ExecPlans

Approved execution plans live here as separate Markdown files. `PLANS.md` at the repository root defines their required structure, maintenance rules, and evidence standard; it does not contain individual plans.

Name each plan with its stable identifier and a short description, such as `PLAN-001-notes-interaction-spike.md`. A progress tracker or exercise that activates a plan should point to that exact file so future agents load only the relevant plan.
